# 用户账号池

站内独立页面 `/account-pool`，菜单「我的账号池」。没有第三方插件、独立服务或管理员密钥。沿用现有 `StatCard`、`Select`、`AutoRefreshButton`、`StatusBadge`、`Pagination`、`EmptyState` 和 `UsageProgressBar`，不使用原生下拉框或复选框。布局依次为概览、操作栏、分组与额度卡片；卡片随页面宽度自动排列，长名称换行，适配暗色与站点主题。支持全屏、分组筛选、分页及 30/60/120 秒自动刷新，刷新偏好保存在浏览器内，后台标签页暂停刷新。筛选下拉菜单挂载在页面容器内，进入全屏后仍可使用。

`GET /api/v1/user/pool-dashboard` 使用本站用户 JWT。来源分组取当前用户未过期、启用的 API Key 的绑定分组，再与 `GetAvailableGroups` 的实时权限结果求交集。用户无法用请求参数指定其他用户或分组；权限校验先于每组 30 秒缓存，撤销权限后缓存不继续授权。

响应为独立白名单 DTO，额度窗口也独立声明，不嵌入管理端结构：用户已有权查看的分组名称、账号 `name`、平台、账号类型、可调度状态、额度窗口、上游余额及采样时间。标题直接取管理员填写的 `name`，为空显示「未命名账号」，不从凭据邮箱补全。不返回凭据中的邮箱、密钥、代理、内部错误或其他分组绑定。Spark 影子账号读取自己的独立额度，母账号仅用于检查共享凭据是否可用，其身份和 global 额度不返回。跨分组相同账号在页面总数中去重；百分比和不同币种不相加。

每张卡片在额度区与更新时间之间放一排共享按钮：「测试连接」「智商测试」，复用管理端现有 `AccountTestModal`、`IQTestModal` 和本站 UI 控件。全屏时弹窗与下拉框跟随全屏容器。普通用户接口位于 `/user/pool-dashboard/groups/:group_id/accounts/:id/{models,models/reasoning,test,pelican-test}`，每次重新验证用户、密钥分组、账号成员关系及用户/分组模型限制；不开放管理端接口。支持多分组密钥。

用户测试只开放目录中允许的文本模型；连接测试使用固定探针，智商测试只开放现有糖果题和鹈鹕动画题，题目由服务端固定，单次运行一个任务。管理员原有自定义提示、并行、探针、定时任务和全局历史保持原有权限。测试每用户最多同时 1 个、每分钟 4 次，全站同时 4 个，账号结束后冷却 10 秒，每次最多 3 分钟。SSE 返回独立白名单事件，原始上游错误、地址、凭据和调试元数据不下发；智商测试输出在完成后整体脱敏，防止敏感字符串跨流片段绕过检查。普通用户历史仅保存在当前弹窗会话，不读取管理员浏览器历史。只有点击测试才发起模型推理，额度自动刷新不触发测试。

OpenAI、Claude 的窗口复用既有被动快照解析；Antigravity 复用账号页的额度缓存，冷缓存由最多 4 个后台任务读取官方额度，每账号至少间隔 60 秒；API Key 账号复用已保存的上游余额快照。没有可靠观测值的平台显示未知。窗口结束、观测超过 15 分钟或余额快照过期后等待新观测，绝不推算已恢复至 100%。额度读取不发起模型推理请求，失败时只显示未知或过期。

新增专用文件列入 `custom/protected-paths.txt`，共享路由、菜单和组装文件继续参与上游合并。测试、类型检查和构建由 GitHub Actions 执行。
